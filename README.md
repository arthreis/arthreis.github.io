# Arthur Reis

Portfólio profissional em React e Vite, em português.

## Desenvolvimento

```bash
npm ci
npm run dev
npm run build
npm run preview
```

O build estático é gerado em `dist/`. Os textos da trajetória,
entregas e competências ficam em `src/pages/home/content.js`.
A antiga âncora `/#/detailed` continua funcionando e direciona
para a seção de trajetória.

A publicação do GitHub Pages é uma etapa separada da prévia local.
